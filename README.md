# shadcn-admin

A modern admin dashboard built with React, TypeScript, TailwindCSS, and shadcn/ui components. This repository includes a main application and a reusable design system package with Storybook documentation.

## What's Inside

- **Main App**: A full-featured admin dashboard with routing, authentication, data tables, and 10+ example pages
- **Design System**: `packages/design-system` — a standalone package of shadcn/ui components with TypeScript definitions
- **Storybook**: Interactive component documentation and development environment

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the main app in development mode:

```bash
pnpm dev
```

Build the design system package:

```bash
pnpm build:ds
```

Run Storybook:

```bash
pnpm storybook
```

Build for production:

```bash
pnpm build
```
